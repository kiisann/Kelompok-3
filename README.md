<h2>✨ Tentang Project</h2>

<p>
<strong>Kalender</strong> adalah program console berbasis C++ yang dirancang untuk
mengimplementasikan logika perhitungan kalender, termasuk pengecekan tahun kabisat
dan jumlah hari dalam setiap bulan.
</p>

<p>
Project ini dibuat sebagai latihan / tugas akademik untuk melatih logika
pemrograman, modular programming, dan penggunaan fungsi dalam C++.
</p>

---

<h2>🚀 Fitur Utama</h2>

<ul>
<li>📆 Menentukan apakah suatu tahun termasuk tahun kabisat</li>
<li>🗓️ Menghitung jumlah hari dalam suatu bulan</li>
<li>🧮 Implementasi logika perhitungan kalender</li>
<li>💻 Tampilan berbasis terminal / console</li>
</ul>

---

<h2>🏗️ Struktur File</h2>

<pre>
Kalender/
│
├── main.cpp
├── kalender.cpp
├── Kabisat.cpp
└── README.md
</pre>

<ul>
<li><strong>main.cpp</strong> → Program utama</li>
<li><strong>kalender.cpp</strong> → Logika sistem kalender</li>
<li><strong>Kabisat.cpp</strong> → Fungsi pengecekan tahun kabisat</li>
</ul>

---

<h2>⚙️ Cara Menjalankan</h2>

<h3>1️⃣ Clone Repository</h3>

<pre>
git clone https://github.com/kiisann/Kalender.git
</pre>

<h3>2️⃣ Compile Program</h3>

Gunakan compiler C++ seperti <strong>g++</strong>:

<pre>
g++ main.cpp kalender.cpp Kabisat.cpp -o kalender
</pre>

<h3>3️⃣ Jalankan Program</h3>

<pre>
./kalender
</pre>

<p><em>(Untuk pengguna Windows: jalankan kalender.exe)</em></p>
